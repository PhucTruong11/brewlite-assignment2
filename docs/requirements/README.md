# Task 1 - Yêu cầu

Đề Assignment 2 nằm ở `assignment2-brief.pdf`. Hồ sơ Assignment 1 được giữ trong `assignment1-user-stories/` để tham khảo và truy vết.

Các file khung đã được tạo để nhóm bổ sung/duyệt trong Sprint 1:

- `context-and-scope.md`: bối cảnh, stakeholder, phạm vi, giả định, ràng buộc, rủi ro.
- `srs.md`: FR/NFR, MoSCoW và tiêu chí chấp nhận có thể kiểm chứng.
- `use-case-checkout.md`: actor, tiền/hậu điều kiện, luồng chính/thay thế/ngoại lệ và mã FR liên quan.
- Use-case diagram tổng quát và use-case trọng tâm, lưu cả nguồn và bản xuất ở `../diagrams/`.

Các file trên chưa được coi là hoàn thành chỉ vì thư mục đã tồn tại.
